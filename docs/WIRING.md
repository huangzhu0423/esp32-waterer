# 接线表

确认的板型：**ESP32-WROOM-32 DevKit，30 针，USB-C，丝印为 `D` 前缀写法**（`D13`/`D2`/`VN`/`VP` 这种）。
确认的传感器：**Capacitive Soil Moisture V2.0.0（丝印另有 HW-390）**，自带 3 针 JST 白插头 + 杜邦线。
6 路传感器 + 6 个 5V USB 小泵 + 6 个逻辑电平 MOSFET，每路接线完全一样，只是引脚号不同。

## 零、先说传感器

- **供电必须是 3V3，不能接 5V。** 这个模块的输出电压跟着供电走，接 5V 时输出会超过 ESP32 ADC 的 3.3V 上限，轻则读数永远顶到 4095，重则损伤引脚。
- 它标称 3.3~5.5V 可用，但配 ESP32 就只能用 3.3V 那一档。单个约 5mA，6 个共 30mA，板载 AMS1117 带得动。
- **不要相信线的颜色。** 白插头出来的三根线红/黑/黄是常见排法，但不同批次会变。看板上丝印：靠近插座那三个焊盘分别标着 `VCC` / `GND` / `AOUT`，按丝印接，别按颜色接。
- 出厂默认干湿点是 2800 / 1150（这个型号的典型区间），实际每片探头差别不小，装好一定要做一次校准。

## 一、引脚对照

| 通道 | 传感器 AOUT | 板上丝印 | 泵 MOS 栅极 | 板上丝印 | 说明 |
|---|---|---|---|---|---|
| CH1 | GPIO36 | **VP** | GPIO13 | **D13** | 传感器脚 input-only |
| CH2 | GPIO39 | **VN** | GPIO18 | **D18** | 同上 |
| CH3 | GPIO34 | **D34** | GPIO19 | **D19** | 同上 |
| CH4 | GPIO35 | **D35** | GPIO23 | **D23** | 同上 |
| CH5 | GPIO32 | **D32** | GPIO25 | **D25** | |
| CH6 | GPIO33 | **D33** | GPIO26 | **D26** | |

传感器全在**右侧排针下段**（D33 往上到 VP），泵全在**两侧中上段**，走线正好分开不打架。

避开的引脚及原因：

| 引脚 | 为什么不能用 |
|---|---|
| D2 / D12 / D15 / EN | strapping 引脚，上电电平决定启动模式 |
| D4 / D5 / D14 | 上电瞬间有 PWM 输出，泵会抖一下 |
| RX0 / TX0（GPIO1/3） | 串口，占了就看不了调试输出 |
| 3V3 / GND / VIN | 电源脚 |
| GPIO6~11 | SPI Flash，根本不引出 |

## 二、每路接线（6 路重复 6 次）

| 从 | 到 | 元件 | 备注 |
|---|---|---|---|
| 传感器 VCC（红） | **3V3** | 导线 | **绝对不要接 5V**，电容式探头 3.3V 供电即可 |
| 传感器 GND（黑） | **GND** | 导线 | |
| 传感器 AOUT（黄） | 对应的 ADC 脚 | 导线 | 见上表 |
| AOUT | GND | **100kΩ 电阻** | 泄放电阻，**必须有**。input-only 脚没有内部下拉，探头一拔读数会乱飘；加了它才能让"断线"稳定表现为读数≈0 |
| 泵 +（红） | 5V 电源正 | 导线 | **不要从板子的 VIN 取电**，见第三节 |
| 泵 −（黑） | MOSFET Drain（漏极） | 导线 | |
| MOSFET Source（源极） | GND | 导线 | **必须与 ESP32 共地** |
| MOSFET Gate（栅极） | 对应的泵脚 | **串 100Ω** | 限流，防止栅极振荡 |
| Gate | GND | **10kΩ 电阻** | 下拉，**这是"上电不浇水"的真正保障**（见下） |
| 泵 + ↔ 泵 − | 反向并联 | **1N4007**（阴极接 +5V） | 续流二极管，吸收泵关断时的反向尖峰，否则迟早打穿 MOS |

## 三、供电总图

> **当前实机分工**：水泵走低边 N-MOS（第二节），**唯一的继电器是探头间歇供电**（第八节）。「6 路泵也改用继电器」是第七节的备选方案，本节电流账按 MOS 方案算。

这台机器有四类负载、两档电压，必须分开供。

| 负载 | 电压 | 单个电流 | 同时最多 | 由谁供 |
|---|---|---|---|---|
| 6 个水泵 | 5V | 0.5~0.8A（启动峰值 1.5A） | 1 路（固件互斥） | 5V 适配器直供，经 MOS 低边开关 |
| 6 个 MOS 栅极 | 3.3V | <1mA（静态） | 6 路 | ESP32 GPIO |
| 探头供电继电器线圈 | 3.3V | 73mA | 间歇 | ESP32 3V3 |
| 6 路探头 | 3.3V | 合计 30mA | 间歇 | 经探头继电器 NO |
| ESP32 | 5V→3V3 | 150~250mA | 常开 | 5V 适配器 VIN（部署）/ USB（调试） |

### 直接接 ESP32 的 3V3 行不行

**可以。** 把账算清楚就明白余量在哪：

| 项目 | 3.3V 侧电流 |
|---|---|
| ESP32 自身（WiFi 发射峰值） | 150~250mA |
| 探头供电继电器线圈（采样窗口才吸合） | 73mA |
| 6 路探头（采样窗口才耗电） | 30mA |
| 6 个 MOS 栅极 | 可忽略 |
| **稳态合计** | **约 353mA** |

USB 口限的是 **5V 侧 500mA**，经 AMS1117 转成 3.3V 后约 **640mA**（效率 85%）。稳态 353mA 还剩近 300mA 余量，MOS 方案比继电器方案宽松得多。

**唯一的危险点是探头继电器吸合瞬间**：线圈浪涌会在几百毫秒内把 3V3 拉出一个坑，电压一跌就是「复位→再复位」。靠两件事排除：

1. **3V3 与 GND 之间加 470~1000µF 电解电容**：吸收吸合浪涌，把瞬态坑填平
2. **确认模块 IN 端有下拉**：断电状态量 **IN 对 DC−**，约 10k 说明有；无穷大就补一个 10k 到 DC−，避免上电高阻窗口乱吸合

做好这两条，直连完全能用。真出症状了（上电时继电器连续「咔哒」、串口刷 `rst:0x1`）再补一个降压模块——那时它是解决方案，不是必需品。

> 如果你更想一步到位、彻底不操心，也可以上 5V→3.3V 降压模块（MP1584 / LM2596，3A 版）把继电器和探头都挪过去。十块左右，代价是多一个模块和几根线。

### 接线

```
5V / 5A 适配器
  ├─ VIN ───────────────── ESP32（部署时；调试可改用 USB 供电）
  ├─ 5V 主干 AWG18 ─────── 汇流排 → 6 个泵 +（各并 1N4007）
  └─ GND ─┬─ ESP32 GND
          ├─ 6 个 MOS Source
          ├─ 探头继电器 DC−
          └─ 6 路探头 GND

ESP32 3V3
  ├─ 探头继电器 DC+（线圈）
  ├─ 探头继电器 COM ── NO ── 6 路探头 VCC（并联）
  └─ 470~1000µF 电解 → GND（关键，见下）

ESP32 GPIO（16 根，见第十节的分配板做法）
  ├─ D27 ─────────────── 探头继电器 IN
  ├─ VP / VN / D34 / D35 / D32 / D33 ── 6 路探头 AOUT（各并 100k 到 GND）
  └─ D13 / D18 / D19 / D23 / D25 / D26 ── 100Ω ── 6 个 MOS Gate（各并 10k 到 GND）

6 个泵 − ── 各自 MOS Drain
```

> **所有 GND 必须连在一起。** 少接一处，继电器 IN 就没有参考电平，表现为乱吸合、时好时坏——这类故障最难查。

**适配器用 5V/5A**：水泵启动电流是额定的 2~3 倍，单泵峰值可达 1.5A；ESP32 约 0.25A。正常工况合计不到 2A，5A 余量充足，即使某路泵卡转也不会把电压拖下来。

### 5A 怎么分配，比买多大更要紧

| 事项 | 要求 | 原因 |
|---|---|---|
| 输出线径 | **AWG18（0.82mm²）以上** | 杜邦线每根只能过 0.5~1A，5A 会发烫甚至熔皮 |
| 分配方式 | **端子台 / 直接焊接** | 面包板单孔约 1A，绝对不能用来分配 5V 主电 |
| 走线 | 泵的正极线单独从适配器拉，不要和探头线捆一起 | 泵启停的电流突变会耦合成干扰，影响 ADC |

> 电源给到 5A，**不代表可以放开多路同时浇水**。固件保持互斥是有意的：6 个泵同时启动峰值接近 9A，这个余量是留给"某一路卡转"的，不是留给并发浇水的。

### 必装的两个电容

| 位置 | 元件 | 作用 |
|---|---|---|
| **ESP32 3V3 ↔ GND** | **470~1000µF 电解 + 0.1µF 瓷片** | 直连方案里这是最关键的一个元件：吸收探头继电器线圈吸合的浪涌，同时兼顾 WiFi 发射的 200mA 级突变。没有它，上电窗口和吸合瞬间都容易把 3V3 拉出坑 |
| 探头继电器模块 DC+ ↔ DC− | 100µF（可选） | 就近缓冲。模块离 ESP32 超过 20cm 时建议补上，短线本身电感就会放大瞬态压降 |

## 四、关于"上电时泵会不会误开"

从 ESP32 复位到 `setup()` 跑起来之间有 **200~300ms** 的 bootloader 窗口，这段时间软件完全管不到。唯一能兜住它的是 **栅极上的 10kΩ 下拉电阻**——它保证 MOS 在没有任何驱动时保持关断。

所以：
- 10k 下拉不是"可选优化"，漏了就会出现"一插电泵就抽一下"。
- 固件里 `pumpBegin()` 在 `setup()` 第一行执行，但那已经是 300ms 之后的事了。

## 五、第一次上电前自检

1. 万用表量每路 Gate 对 GND，应为 0V（不接 ESP32 时）。
2. 量 5V 与 GND 之间不能短路。
3. 先只接 ESP32 + 传感器，不接泵，上电看网页能不能读到 6 路湿度。
4. 确认读数正常后，再接一路泵测试开合。**不要一上来就接满 6 路。**

## 六、常见故障对照

| 现象 | 大概原因 |
|---|---|
| 上电后反复重启、串口刷 `rst:0x1 (POWERON_RESET)` | 继电器线圈浪涌把 3V3 拉塌了。先按第三节补足 470~1000µF 电容；仍复发说明模块 IN 没有下拉，给每个 IN 补 10k 到 DC−，或者改用降压模块 |
| 六路同时显示「探头无供电」 | 探头供电继电器没吸合 / 线圈断 / 3V3 没供上。**不是六个探头一起坏了**，先量继电器 NO 端有没有 3.3V |
| 网页显示某路 raw < 400 且标记故障 | 探头没插好 / AOUT 线断 / 忘了接 VCC / 悬空引脚漂到百位级 |
| 某路湿度一直 0%，但探头插在湿土里 | 干湿点没校准，去网页点"以当前值为湿点" |
| 浇水时其他通道读数乱跳 | 没共地，或 3V3 缺 100µF 电容 |
| 一插电泵就转一下 | 栅极缺 10kΩ 下拉 |
| 网页连不上 | 先连热点 `AutoWater-XXXX`（密码为空），再看设置页 |
| 反复重启 | 5V 带不动，或 3.3V 被继电器线圈浪涌拉塌。电源见第三节，别用电脑 USB 口 |

## 七、改用继电器模块（TONGLING JQC-3FF-S-Z）

如果没有 MOS 管、手上是这种红色继电器模块，也能用，接线如下。**每路一个模块。**

### 线圈电压先确认

继电器本体侧面印着线圈电压（`03VDC` / `05VDC` / `12VDC`），**模块的 VCC 必须等于这个值**：

- 5V 线圈接 3.3V → 吸不动，触点半接触，会打火发热
- 3V 线圈接 5V → 线圈过流发热，几小时就烫手

### 输入端（3 针排针，丝印 VCC / GND / IN）

| 端子 | 接到 | 说明 |
|---|---|---|
| **DC+** | **ESP32 3V3**（本机这 6 个都是 3.3VDC 线圈） | 接 5V 会烧线圈。6 路并联前先看第三节的电流账与电容要求 |
| **DC−** | GND | **必须与 ESP32 共地**，否则 IN 没有参考电平 |
| **IN** | 对应泵脚（D13/D18/D19/D23/D25/D26） | 3.3V 逻辑直接驱动光耦 |

### 输出端（3 位蓝色端子 NO / COM / NC）

| 端子 | 接到 | 说明 |
|---|---|---|
| COM | 5V 电源正 | 触点公共端 |
| **NO** | 水泵 +（红线） | 常开，**只能用这个**：不吸合时断电，泵不转 |
| NC | 空着 | 常闭，断电时反而导通，用它会一直浇水 |

水泵 −（黑线）直接回 5V 电源负极，不经过继电器。

> 继电器只切**一根线**（水泵正极），不要同时切正负极。

### 黄色跳线：必须选高电平触发

板上标 `High/Low Level Trigger` 的黄色跳线决定 IN 的极性。**固件默认高电平开泵**，所以：

- 跳线设成 **H（高电平触发）**
- 如果你的模块只有低电平触发、或跳线帽掉了：把 `config.h` 里 `PUMP_ACTIVE_LOW` 改成 `1` 重新烧录。**不改一定会出事**——固件把引脚拉低当作"关"，模块却认为"开"，上电后泵一直转。

### 3.3V 能不能驱动 5V 模块

绝大多数带光耦的 JQC-3FF 模块，3.3V 高电平就能可靠触发（光耦只吃 3~5mA）。但个别批次的限流电阻偏大，3.3V 电流不够。**通电前先空载测**：

1. 只接 VCC/GND，IN 悬空 → 继电器应不吸合
2. IN 接 3V3 → 应听到"咔哒"一声吸合
3. IN 接 GND → 应释放

只要第 2 步不吸合或吸合发抖，就是电平/电流不够，换 MOS 管方案。

### 和 MOS 管方案的差别

| | 继电器 | 低边 MOS |
|---|---|---|
| 静音 | 有"咔哒"声 | 完全无声 |
| 寿命 | 机械触点，约 10 万次 | 无限次 |
| 上电误动作 | 靠模块自身上拉 + 跳线 | 靠 10k 栅极下拉 |
| 触点打火 | 泵停机瞬间有轻微火花 | 无 |
| 体积 | 大 | 小 |

每天开合几次的话，10 万次够用好几年，继电器完全能胜任。水泵两端仍建议并一只 1N4007（阴极接 +5V），能明显减少触点火花。

## 八、探头供电继电器（间歇采样）

固件默认**每 30 分钟给探头供电一次，采完立刻断电**，其余时间传感器完全断电。

这一路是可选的：不接的话固件照样工作（探头一直带电，只是不省电、不延寿），所以可以先烧固件验证逻辑，硬件后补。

### 为什么值得加

电容式探头长期通电会让极板电化学极化，一两年就漂。六路合计约 30mA，断电后平均只剩 0.015mA。省电是次要的，**主要是延寿**。

### 接线（占用模块的一个空闲通道）

输出端：

| 端子 | 接到 | 说明 |
|---|---|---|
| COM | **3V3** | 触点公共端。线圈仍是 5V，但触点和线圈完全隔离，互不影响 |
| **NO** | 传感器 VCC 母线 | 六路探头的 VCC（红线）并在一起接这里 |
| NC | 空着 | 常闭，不吸合时反而供电，接错等于白做 |

输入端：**VCC 接 3V3**、GND 共地，**IN 接 GPIO27（D27）**。

> 这块 JQC-3FF-S-Z 外壳印着 `3.3VDC`，是 **3.3V 线圈版**，VCC 必须接 3V3，接 5V 会把线圈烧了。买模块前先看这个数字：`05VDC` 的才接 5V。
>
> 3.3V 线圈单只吸合约 73mA。吸合瞬间的浪涌容易把 3V3 拉低、导致 ESP32 复位，建议在模块 VCC 与 GND 之间并一只 **100~470μF** 电解电容缓冲。

黄色跳线同样设 **H（高电平触发）**，对应 `config.h` 里 `SENSOR_PWR_ACTIVE_LOW = 0`。

> 若模块只有低电平触发，把 `SENSOR_PWR_ACTIVE_LOW` 改成 `1` 重新烧录。**不改会正好反过来**——固件以为拉高是通电，实际拉高是断电，于是"采样时断电、待机时通电"，六路读数全是 0，全部判断线，水泵全锁。

### 只断 VCC，不动 GND

探头的 GND 和 AOUT 始终接着，只切 VCC。**绝对不要改成断 GND**——那样探头 AOUT 会经内部电路继续带电压，电流从 ESP32 的 ADC 保护二极管倒灌进芯片。

### 触点会氧化

30mA 属于"干电流"，银触点不产生电弧自清洁，长期可能氧化、接触电阻变大，表现是六路读数同时偏高。怀疑时量触点两端压降，超过 0.5V 就该换模块。想彻底免除这项维护就换 P-MOS 高边开关（见 `config.h` 里方案 B）。

### 扩到 20 路以上要分组

一个继电器带 8~10 路没问题，带满 32 路就有隐患：每路探头内部有 10~47μF 滤波电容，32 路并起来是 300~1500μF。继电器吸合瞬间从 0 充到 3.3V，冲击电流可达几十安（微秒级），反复几次触点就会粘连——而粘连是渐进的，起初只是读数间歇性乱跳，极难归因。

**按 8 路一组分开供**：

| 组 | 探头通道 | 继电器 IN | VCC 母线 |
|---|---|---|---|
| 1 | 1~8 | GPIO27 | 母线 A |
| 2 | 9~16 | GPIO16 | 母线 B |
| 3 | 17~24 | GPIO17 | 母线 C |
| 4 | 25~32 | GPIO21 | 母线 D |

每组一个继电器 + 一条独立的 VCC 母线。三个好处：冲击电流降到 1/4；某组继电器坏了只影响 8 路；供电线跟着探头分布走，走线短、压降小。

> 当前固件只有一路供电控制（`PIN_SENSOR_PWR` = GPIO27），对应第 1 组。扩到多组时要把这个宏改成数组，并在 `sensors.cpp` 的 `sensorPowerOn()` / `sensorPowerOff()` 里按组分别操作。这一步最好和 MUX、`CHANNEL_COUNT` 一起改，只折腾一次。

如果实在想用一组带满 32 路，至少在 NO 与 VCC 母线之间串一只 **NTC 热敏电阻**（MF72-5D11，冷态 5Ω / 热态 0.2Ω）限制充电电流。代价是正常工作时约有 0.03V 压降，对探头可以接受。

### 怎么验证

1. 万用表接传感器 VCC 母线，平时应为 **0V**
2. 网页「设备」里看「下次采集」倒计时，到点时 VCC 跳到 **3.3V**，约 1 秒后回到 0V
3. 断电期间量任意一路 AOUT：应接近 0V（100k 下拉保证）。若还有 1V 以上虚电压，说明断的是 GND 不是 VCC，或者继电器接错端子

## 九、最小验证：1 个探头 + 1 个探头供电继电器 + 1 路 MOS 泵

**当前实机的分工**：唯一的继电器是**探头间歇供电**（GPIO27），**不是**泵继电器；水泵走低边 N-MOS（D13）。第一次上电不要一次接满 6 路，只验证通道 1（CH1），其余 5 路空着显示「故障 / 断线」是正常的。

### 探头侧：继电器只切 VCC

| 元件 | 端子 | 接到 | 备注 |
|---|---|---|---|
| 供电继电器（3.3V 线圈） | DC+ | ESP32 **3V3** | 先看外壳印字：`03VDC` 接 3V3，`05VDC` 接 5V |
| | DC− | ESP32 **GND** | 必须共地 |
| | IN | **D27 / GPIO27** | `PIN_SENSOR_PWR` |
| | 跳线 | **H（高电平触发）** | `SENSOR_PWR_ACTIVE_LOW = 0`，拉高才通电 |
| | **COM** | ESP32 **3V3** | 触点公共端 |
| | **NO** | 探头 **VCC** | NC 空着 |
| 探头 HW-390 | VCC | 继电器 **NO** | 不直接接 3V3 |
| | GND | ESP32 **GND** | **始终直连，不经过继电器** |
| | AOUT | **VP / GPIO36** | 通道 1 的 ADC 脚 |
| | AOUT ↔ GND | **100kΩ 电阻** | 必须有；断电时把 AOUT 拉到 0，断线才能稳定判成 raw≈0 |

> **只断 VCC，绝对不要改成断 GND**：探头断电后 AOUT 会经内部电路继续带电，电流从 ADC 引脚的 ESD 保护二极管倒灌进芯片。
>
> 跳线拨错成低电平触发会正好反过来：采样时断电、待机时通电，六路读数全 0 判断线，水泵全锁。

### 水泵侧：低边 N-MOS

| 从 | 到 | 元件 | 备注 |
|---|---|---|---|
| 泵 +（红） | 5V 电源正 | 导线 | **不要从板子 VIN 取电** |
| 泵 −（黑） | MOS **Drain** | 导线 | |
| MOS **Source** | GND | 导线 | 与 ESP32 共地 |
| MOS **Gate** | **D13 / GPIO13** | **串 100Ω** | 通道 1 泵脚 |
| Gate | GND | **10kΩ 下拉** | 上电不误开的关键 |
| 泵 + ↔ 泵 − | 反向并联 | **1N4007** | 阴极接 +5V，吸收关断尖峰 |

`PUMP_ACTIVE_LOW = 0`（高电平开泵）与 N-MOS 栅极高电平导通一致，**不用改固件**。

### 上电自检

1. 万用表量探头 VCC：待机 0V，采样窗口（约 1 秒）跳到 3.3V 再回落；一直 0V 说明跳线极性或 IN 脚接错。
2. 网页预期：只有 CH1 显示湿度（干土约 2600~2900，湿土约 1000~1300），CH2~CH6 全为故障。
3. 点「浇 15s」：D13 变高、MOS 导通、泵转 15 秒。可先空载，用万用表量 Gate 是否为 3.3V。
4. CH1 若仍是故障：量采样窗口内 VCC 有没有 3.3V、AOUT 接牢没、100k 并上没。
5. 所有 GND 共地；3V3 ↔ GND 并 470µF 电容吸收继电器吸合浪涌。

### 端子形状不匹配：需要过渡线

探头三根线末端是**杜邦头**，ESP32 是**公排针**，继电器两侧却是**螺丝压接端子**（`DC+ / DC- / IN` 与 `NO / COM / NC`）。螺丝孔只能压裸铜线，杜邦头插不进去，所以凡是要接继电器的一端都得做一根「一头是插头、一头是裸线」的过渡线：

| 继电器端子 | 对面 | 过渡线做法 |
|---|---|---|
| `NO` | 探头红线（杜邦母头） | **公对公杜邦线**：公针插母头，另一头剪掉剥皮 5mm |
| `COM` / `DC+` / `DC−` / `IN` | ESP32 `3V3` / `GND` / `D27` 公排针 | **母对母杜邦线**：一头母头插排针，另一头剪掉剥皮 5mm |

多股软线先拧紧再镀锡，露铜别超过 6mm（隔壁端子很近，容易搭短路），拧紧后轻拉确认不脱；**断电接线**。想长期可靠就剥皮后压一只管形冷压端子（E0508）再进螺丝孔。探头的 GND 与 AOUT 是杜邦母头，直接插 ESP32 的 `GND` / `VP` 排针即可，不用转接。100kΩ 电阻两端是硬引脚，用面包板或焊两根杜邦线跨接在 AOUT 与 GND 之间。

> **两个常见误区**
> 1. 杜邦公针（0.64mm 方针）**不能**直接塞进螺丝孔拧紧当裸线用：压片夹不紧、接触只有一条线，继电器每 30 分钟间歇吸合的振动会让它松动；针体偏长还容易搭到隔壁端子短路。临时应急有时能导通，但探头供电这路一旦接触不良，采样窗口会读到六路全 0、被判成「探头无供电」，故障极难归因。
> 2. 模块左侧黄色跳线帽旁那组排针是 `High/Low Level Trigger` 的 **H/L 选择跳线**，不是输入端，别把 IN 线插到那里。这块板的输入只有蓝色螺丝端子 `DC+ / DC- / IN`。

### 一个 3V3 针要带两根线

`COM`（触点 → 探头 VCC）和 `DC+`（线圈电源）是**两条互不相连的回路**，继电器触点与线圈本来就隔离，所以两处都得取 3.3V，不能只接一处。三种做法：

1. **最省事**：在 `COM` 螺丝孔里同时压两根线 —— 一根来自 ESP32 `3V3`，另一根短接到 `DC+`。两根多股线先互相拧紧/镀锡再一起插进去拧紧，轻拉两根都不脱。这样 ESP32 的 `3V3` 只出一根线。
2. **最清爽（推荐）**：用面包板或端子台做电源分配，`3V3` 引到同一行，`COM` 与 `DC+` 各接这一行。
3. 焊一根一分二短线：两根裸端拧在一起焊到带母头的第三根线上，母头插 `3V3`。

线圈约 73mA + 探头约 5mA，加 ESP32 自身约 250mA，板载 3V3 稳压器带得动；吸合瞬间有浪涌，`3V3` ↔ `GND` 并 470µF 电解更稳。

`GND` 一侧同样要接多路（`DC−`、探头 GND、100k 一端，接泵后还有 MOS Source）。**优先用板上两个 GND 针分开走**：右侧 `GND`（`VIN` 下面那个）接继电器 `DC−`，左侧 `GND`（`3V3` 下面那个）接探头 GND 与 100k。两个 GND 内部是连通的，但分开走线能避免线圈吸合浪涌耦合进 ADC 读数。还不够分再用面包板做公共地，或把 `DC−` 螺丝孔当汇流点（就是 `COM` 孔压两根线的对称做法：孔内同时压去 ESP32 GND、去探头 GND、100k 一端的线，多股线先互拧镀锡）。

`DC−` 到 GND 的连接本身：取一根杜邦线，**留母头插 ESP32 `GND` 排针，另一头剪掉剥 5mm 皮**，裸铜线压进 `DC−` 螺丝孔拧紧；接完轻拉不脱，万用表通断档量 ESP32 GND ↔ 探头 GND ↔ `DC−` 应全通。**断电接线**。

## 十、6 路全量落地：别把线都拉回板子

照第二节逐路接，6 路 × 9 根 ≈ 54 根，加共享线快 60 根，看着吓人。**实际真正回到 ESP32 的只有 16 根**，其余都能在元件附近并掉。关键是先把「共享母线」和「每路独有信号」分开，而不是 6 套线各拉各的。

### 1. 共享的只有 4 条母线

| 母线 | 电压 | 从哪来 | 分给谁 | 线径 |
|---|---|---|---|---|
| `VCC_S` | 3.3V（经探头继电器 NO） | ESP32 3V3 → 继电器 COM→NO | 6 路探头 VCC | 细线，合计才 30mA |
| `GND` | 0 | 5V 适配器 GND | 探头 GND / 100k / 继电器 DC− / 6 个 MOS Source | 细线 + 1 根粗回流 |
| `5V_P` | 5V | 5V 适配器正极 | 6 个泵 + | **AWG18 主干**，泵电流走这里 |
| `GND_P` | 0 | 汇流排 | 6 个 MOS Source → 泵 − 回路 | 每路 AWG22 以上 |

6 个探头 VCC 并成一条、6 个泵 + 并成一条、所有 GND 并成一条，这三条做出来，线立刻少一半。

### 2. ESP32 上一共只插 16 根针

| 用途 | 针数 | 板上丝印 |
|---|---|---|
| 6 路 AOUT | 6 | VP / VN / D34 / D35 / D32 / D33 |
| 6 路 Gate | 6 | D13 / D18 / D19 / D23 / D25 / D26 |
| 探头继电器 IN | 1 | D27 |
| 3V3 / GND | 3 | 3V3 ×1、GND ×2（分开走，见第九节） |

### 3. 四种散件就地焊，一根都不回板子

| 元件 | 焊在哪两点之间 | 位置 |
|---|---|---|
| 100kΩ | 探头 AOUT ↔ GND | 探头插头根部，套热缩管 |
| 100Ω | ESP32 Gate 线 ↔ MOS Gate | MOS 这头串进去 |
| 10kΩ | MOS Gate ↔ GND | MOS 这头 |
| 1N4007 | 泵 + ↔ 泵 −（阴极朝 +5V） | 泵接线端子处 |

这些东西如果在面包板上全拉回 ESP32 旁边，才是「线爆炸」的真正原因。焊在元件那头，每路只剩一根 AOUT 和一根 Gate 是长线。

### 4. 推荐结构：一块分配板

用一块万能板或两组 6 位螺丝端子台，做 3 条汇流排，ESP32 用一束 16 芯排线接过来：

```
ESP32 ── 16 芯排线 ──> [ 分配板 ]
                          │ 汇流排：VCC_S(3V3) / GND / 5V_P(AWG18)
                          ├─ 探头侧 6 位端子 ── 8 芯干线 ──> 6 个探头
                          │    每路只出 AOUT；VCC/GND 在端子上并
                          └─ 泵侧   6 位端子 ── 6 根 Gate + 5V 粗线
                               每路只出 Gate；5V 与 Drain 回路在板上闭环
```

这样 ESP32 上是一束整齐的排线，不是几十根散杜邦线；机箱里探头线束走左下、泵 5V 粗线走右上，**强弱电不平行长距离并行**，泵启停的电流突变才不会耦合进 ADC。

**探头侧 8 芯干线**：`VCC_S + GND + 6×AOUT = 8 芯`，用一截超五类网线就够（30mA，线径完全够），拉到花盆区再分叉，末端每路并 100k。**泵侧 5V 千万别走网线**，单独拉 AWG18 到汇流排。

### 5. 颜色和编号

| 线色 | 用途 |
|---|---|
| 红 | 5V 泵正极（粗） |
| 橙 / 白 | 3V3 探头 VCC（经继电器 NO） |
| 黑 | GND |
| 黄 | 探头 AOUT |
| 蓝 | MOS Gate |

**每根线两端都贴 `CH1`~`CH6` 标签**。6 路一模一样的线，不贴标签的话，查一次接错的 AOUT 要花半小时。线长留 10cm 余量，方便以后换探头。

### 6. 分三批上，别一次接满

| 批次 | 做什么 | 验收 |
|---|---|---|
| 1（现在） | 补齐 100kΩ，接 1 路 MOS 泵（D13） | CH1 `raw≈2600~2900 / flt=0`，点浇水 Gate 变 3.3V |
| 2 | 扩到 CH1~CH3 | 每扩一路读一次 `/api/state`：新路 `flt=0`，其余仍 `flt=1`；逐路点浇水，其他路读数不跳 |
| 3 | 补齐 6 路 | 六路 `flt=0`，做一次干湿点标定，再启用自动 |

每批之间**断电接线**，接完先验共地（万用表通断档量 ESP32 GND ↔ 探头 GND ↔ `DC−` ↔ MOS Source 全通）。

### 7. 省事替代：成品多路 MOS 板

买一块 8 路逻辑电平 MOS 驱动板，可以一次省掉 6×(100Ω + 10k + 1N4007) 的散件和焊接。下单前必须确认四条：

1. **低边 N-MOS**（切泵负极），不是高边、也不是 P 沟道
2. **3.3V 栅极能完全导通**（AO3400 / IRLB8721 一类），IRF520 那种 5V 才够的会半导通发热
3. **每路自带 10k 栅极下拉**，否则上电窗口泵会误转
4. **共地**，板子 GND 与 ESP32 GND 必须连

> 不建议改用常见的「8 路继电器板」：那些板大多是 **5V 供电 + 低电平触发**，而固件是 `PUMP_ACTIVE_LOW = 0`（高电平开泵），接上去会**一上电 6 个泵全开**。真要用就得把 `PUMP_ACTIVE_LOW` 改成 `1` 重新烧录，并按第七节重算 3V3 电流账。

### 8. 六路版上电总自检

1. 万用表通断：所有 GND 全通；5V ↔ GND 不短路
2. 未接 ESP32 时，量 6 个 Gate 对 GND 全为 0V（10k 下拉生效）
3. 先只接探头不接泵：六路 `raw` 都在 1000~3000 且 `flt=0`，否则查 VCC 窗口、AOUT、100k
4. 逐路点「浇 15s」，一次只开一路：对应泵转、**其他路读数不乱跳**（跳了就是共地或 3V3 电容没做好）
5. `3V3 ↔ GND` 的 470µF 电解别漏；探头继电器吸合瞬间最容易把 3V3 拉塌
