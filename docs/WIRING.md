# 接线表

确认的板型：**ESP32-WROOM-32 DevKit，30 针，USB-C，丝印为 `D` 前缀写法**（`D13`/`D2`/`VN`/`VP` 这种）。
确认的传感器：**Capacitive Soil Moisture V2.0.0（丝印另有 HW-390）**，自带 3 针 JST 白插头 + 杜邦线。
6 路传感器 + 6 个 5V USB 小泵 + 6 个逻辑电平 MOSFET，每路接线完全一样，只是引脚号不同。

## 零、先说传感器

- **供电必须是 3V3，不能接 5V。** 这个模块的输出电压跟着供电走，接 5V 时输出会超过 ESP32 ADC 的 3.3V 上限，轻则读数永远顶到 4095，重则损伤引脚。
- 它标称 3.3~5.5V 可用，但配 ESP32 就只能用 3.3V 那一档。单个约 5mA，6 个共 30mA，板载 AMS1117 带得动。
- **不要相信线的颜色。** 白插头出来的三根线红/黑/黄是常见排法，但不同批次会变。看板上丝印：靠近插座那三个焊盘分别标着 `VCC` / `GND` / `AOUT`，按丝印接，别按颜色接。
- 出厂默认干湿点是 2800 / 1150（这个型号的典型区间），实际每片探头差别不小，装好一定要做一次校准。

## 一、引脚对照

| 通道 | 传感器 AOUT | 板上丝印 | 泵 MOS 栅极 | 板上丝印 | 说明 |
|---|---|---|---|---|---|
| CH1 | GPIO36 | **VP** | GPIO13 | **D13** | 传感器脚 input-only |
| CH2 | GPIO39 | **VN** | GPIO18 | **D18** | 同上 |
| CH3 | GPIO34 | **D34** | GPIO19 | **D19** | 同上 |
| CH4 | GPIO35 | **D35** | GPIO23 | **D23** | 同上 |
| CH5 | GPIO32 | **D32** | GPIO25 | **D25** | |
| CH6 | GPIO33 | **D33** | GPIO26 | **D26** | |

传感器全在**右侧排针下段**（D33 往上到 VP），泵全在**两侧中上段**，走线正好分开不打架。

避开的引脚及原因：

| 引脚 | 为什么不能用 |
|---|---|
| D2 / D12 / D15 / EN | strapping 引脚，上电电平决定启动模式 |
| D4 / D5 / D14 | 上电瞬间有 PWM 输出，泵会抖一下 |
| RX0 / TX0（GPIO1/3） | 串口，占了就看不了调试输出 |
| 3V3 / GND / VIN | 电源脚 |
| GPIO6~11 | SPI Flash，根本不引出 |

## 二、每路接线（6 路重复 6 次）

| 从 | 到 | 元件 | 备注 |
|---|---|---|---|
| 传感器 VCC（红） | **3V3** | 导线 | **绝对不要接 5V**，电容式探头 3.3V 供电即可 |
| 传感器 GND（黑） | **GND** | 导线 | |
| 传感器 AOUT（黄） | 对应的 ADC 脚 | 导线 | 见上表 |
| AOUT | GND | **100kΩ 电阻** | 泄放电阻，**必须有**。input-only 脚没有内部下拉，探头一拔读数会乱飘；加了它才能让"断线"稳定表现为读数≈0 |
| 泵 +（红） | 5V 电源正 | 导线 | **不要从板子的 VIN 取电**，见第四节 |
| 泵 −（黑） | MOSFET Drain（漏极） | 导线 | |
| MOSFET Source（源极） | GND | 导线 | **必须与 ESP32 共地** |
| MOSFET Gate（栅极） | 对应的泵脚 | **串 100Ω** | 限流，防止栅极振荡 |
| Gate | GND | **10kΩ 电阻** | 下拉，**这是"上电不浇水"的真正保障**（见下） |
| 泵 + ↔ 泵 − | 反向并联 | **1N4007**（阴极接 +5V） | 续流二极管，吸收泵关断时的反向尖峰，否则迟早打穿 MOS |

## 三、全局必装

| 位置 | 元件 | 作用 |
|---|---|---|
| ESP32 3V3 ↔ GND | 100µF 电解 + 0.1µF 瓷片 | WiFi 发射瞬间电流突变 200mA 级，没有它会拉低 3V3 导致 ADC 读数乱跳甚至复位 |
| 5V 电源 GND ↔ ESP32 GND | 导线 | 不共地则 MOS 栅极没有参考电平，泵会乱开 |
| 5V 电源 | 5V / **2A 以上**，独立适配器 | 单个小泵启动电流 0.5~0.8A，固件保证同时只有一路运行，2A 足够 |

**供电怎么接**：板子上的 `VIN` 是 5V 直通脚，但它的走线只够给板子自己用（USB 口限流约 500mA）。6 个泵必须接**独立的 5V/2A 适配器**，只把该适配器的 GND 和板子的 GND 连起来共地，5V 不要并到 VIN 上。

板载 AMS1117 供 3V3，6 个电容式传感器的总电流约 30mA，完全够用，不用担心。

## 四、关于"上电时泵会不会误开"

从 ESP32 复位到 `setup()` 跑起来之间有 **200~300ms** 的 bootloader 窗口，这段时间软件完全管不到。唯一能兜住它的是 **栅极上的 10kΩ 下拉电阻**——它保证 MOS 在没有任何驱动时保持关断。

所以：
- 10k 下拉不是"可选优化"，漏了就会出现"一插电泵就抽一下"。
- 固件里 `pumpBegin()` 在 `setup()` 第一行执行，但那已经是 300ms 之后的事了。

## 五、第一次上电前自检

1. 万用表量每路 Gate 对 GND，应为 0V（不接 ESP32 时）。
2. 量 5V 与 GND 之间不能短路。
3. 先只接 ESP32 + 传感器，不接泵，上电看网页能不能读到 6 路湿度。
4. 确认读数正常后，再接一路泵测试开合。**不要一上来就接满 6 路。**

## 六、常见故障对照

| 现象 | 大概原因 |
|---|---|
| 网页显示某路 raw ≈ 0 且标记故障 | 探头没插好 / AOUT 线断 / 忘了接 VCC |
| 某路湿度一直 0%，但探头插在湿土里 | 干湿点没校准，去网页点"以当前值为湿点" |
| 浇水时其他通道读数乱跳 | 没共地，或 3V3 缺 100µF 电容 |
| 一插电泵就转一下 | 栅极缺 10kΩ 下拉 |
| 网页连不上 | 先连热点 `AutoWater-XXXX`（密码为空），再看设置页 |
| 反复重启 | 5V 电源带不动，换 2A 以上独立电源，别用电脑 USB 口 |

## 七、改用继电器模块（TONGLING JQC-3FF-S-Z）

如果没有 MOS 管、手上是这种红色继电器模块，也能用，接线如下。**每路一个模块。**

### 线圈电压先确认

继电器本体侧面印着线圈电压（`03VDC` / `05VDC` / `12VDC`），**模块的 VCC 必须等于这个值**：

- 5V 线圈接 3.3V → 吸不动，触点半接触，会打火发热
- 3V 线圈接 5V → 线圈过流发热，几小时就烫手

### 输入端（3 针排针，丝印 VCC / GND / IN）

| 继电器引脚 | 接到 | 说明 |
|---|---|---|
| VCC | 5V 电源正（线圈 5V）或 3V3（线圈 3.3V） | 线圈供电，**不要**从 ESP32 的 VIN 取大电流 |
| GND | GND | **必须与 ESP32 共地**，否则 IN 没有参考电平 |
| IN | 对应泵脚（D13/D18/D19/D23/D25/D26） | 3.3V 逻辑直接驱动光耦 |

### 输出端（3 位蓝色端子 NO / COM / NC）

| 端子 | 接到 | 说明 |
|---|---|---|
| COM | 5V 电源正 | 触点公共端 |
| **NO** | 水泵 +（红线） | 常开，**只能用这个**：不吸合时断电，泵不转 |
| NC | 空着 | 常闭，断电时反而导通，用它会一直浇水 |

水泵 −（黑线）直接回 5V 电源负极，不经过继电器。

> 继电器只切**一根线**（水泵正极），不要同时切正负极。

### 黄色跳线：必须选高电平触发

板上标 `High/Low Level Trigger` 的黄色跳线决定 IN 的极性。**固件默认高电平开泵**，所以：

- 跳线设成 **H（高电平触发）**
- 如果你的模块只有低电平触发、或跳线帽掉了：把 `config.h` 里 `PUMP_ACTIVE_LOW` 改成 `1` 重新烧录。**不改一定会出事**——固件把引脚拉低当作"关"，模块却认为"开"，上电后泵一直转。

### 3.3V 能不能驱动 5V 模块

绝大多数带光耦的 JQC-3FF 模块，3.3V 高电平就能可靠触发（光耦只吃 3~5mA）。但个别批次的限流电阻偏大，3.3V 电流不够。**通电前先空载测**：

1. 只接 VCC/GND，IN 悬空 → 继电器应不吸合
2. IN 接 3V3 → 应听到"咔哒"一声吸合
3. IN 接 GND → 应释放

只要第 2 步不吸合或吸合发抖，就是电平/电流不够，换 MOS 管方案。

### 和 MOS 管方案的差别

| | 继电器 | 低边 MOS |
|---|---|---|
| 静音 | 有"咔哒"声 | 完全无声 |
| 寿命 | 机械触点，约 10 万次 | 无限次 |
| 上电误动作 | 靠模块自身上拉 + 跳线 | 靠 10k 栅极下拉 |
| 触点打火 | 泵停机瞬间有轻微火花 | 无 |
| 体积 | 大 | 小 |

每天开合几次的话，10 万次够用好几年，继电器完全能胜任。水泵两端仍建议并一只 1N4007（阴极接 +5V），能明显减少触点火花。
