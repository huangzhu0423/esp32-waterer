# 打一块载板：把 60 根线变成一束排线 + 若干端子

## 零、结论与边界

**可以打，推荐打。** 第十节的「分配板」本质就是一块手工版本的 PCB，把 3 条汇流排、6 路 MOS、24 个阻容、全部端子固化到板上，飞线只剩探头线和泵线。

三条边界必须先划清楚，否则打回来的板装不上或不能用：

| 不进 PCB | 原因 | 正确做法 |
|---|---|---|
| ESP32 芯片 / WiFi 射频 | 射频布局、天线净空、阻抗不是 DIY 能一次做对的 | 用 **2×15 排母**把现成的 DevKit 模块插上去，坏了也能换 |
| 6 个水泵本体 | 大电流、要防水、要能单路更换 | 板上只留 **2P 可插拔螺丝端子** |
| 6 个探头本体 | 线要拉到花盆，长度不定 | 板上只留 **3P 可插拔端子** |

> **最容易被忽略的坑**：ESP32 DevKit 是板载 PCB 天线。载板在天线投影区域**绝不能铺铜、不能放元件、不能走线**，最好让模块天线那一端**伸出板边 5mm 以上**。不做净空，WiFi 会明显变差甚至连不上路由器，而远程页全靠 WiFi。

**排针中心距要实测**：30 针 DevKit 常见两排中心距 **25.4mm**，但也有 **22.86mm** 的窄版。下单前用游标卡尺量手上这块，再定两个排母的间距；排母用 2.54mm 间距、2×15。

## 一、板子规格

| 项目 | 取值 |
|---|---|
| 层数 | **2 层**（6 路低速直流，没必要 4 层） |
| 板材 / 板厚 | FR-4 / **1.6mm** |
| 铜厚 | 1oz 够用，**2oz 更稳**（泵 1.5A 峰值压降更小，加价不多） |
| 建议尺寸 | 约 **100 × 75mm**，压在 10×10cm 内打样最便宜 |
| 最小线宽 / 线距 | 0.25mm / 0.25mm（常规 6/6mil 工艺） |
| 过孔 | 0.6mm 孔 / 0.3mm 钻，盖油 |
| 表面处理 | 无铅喷锡或沉金；绿油白字 |
| 安装孔 | 4 × M3（孔径 3.2mm），四角各留 5mm 禁布区 |
| 打样 | 2 层 10×10cm 内通常是几十元 / 5 片、2~4 天出货，**以官网实时报价为准** |

## 二、板上集成什么

| 区域 | 内容 |
|---|---|
| ESP32 插座区 | 2×15 排母 ×2（或一条 2×15 双排座）、3V3 去耦、天线净空区 |
| 汇流排 | 3V3（VCC_S）、GND 地平面、5V_P 粗铜皮，横贯板中部 |
| 低边驱动区 | 6 × N-MOS + 每路 100Ω / 10k / 1N4007 / 100nF |
| 探头信号区 | 每路 100k 下拉，可选 1k + 100nF 的 RC 滤波 |
| 探头供电 | V1 留 6P 端子外接继电器模块；V2 焊 P-MOS 高边（见第六节） |
| 端子区 | 5V 输入 2P、泵 6×2P、探头 6×3P，全部可插拔 |
| 测试点 | 每路 Gate / AOUT 各 1 个，3V3 / 5V / GND 各 1 个 |

**丝印必须标**：`CH1`~`CH6`、每个 ESP32 引脚的丝印名（`VP/VN/D34/D35/D32/D33`、`D13/D18/D19/D23/D25/D26`、`D27`）、电解电容 `+`、1N4007 阴极方向、所有端子极性。装错一根线要拆半天，丝印是最便宜的保险。

## 三、网络表

完整逐行版见 [`pcb/netlist.csv`](pcb/netlist.csv)，画原理图时按它逐个核对，避免漏网。主干网络：

| 网络 | 从 | 到 | 线宽 / 做法 |
|---|---|---|---|
| `5V_P` | 5V 输入 + | 6 个泵端子 1 脚 | **≥2mm 铜皮或铺铜区**，1.5A 峰值 |
| `PGND` | 5V 输入 − | 6 个 MOS Source | 底层**整片地平面** |
| `PUMP1_N`~`PUMP6_N` | 泵端子 2 脚 | 对应 MOS Drain | ≥1.0mm，每路 0.8A |
| `GATE1`~`GATE6` | ESP32 泵脚 | 串 100Ω → MOS Gate | 0.3mm |
| `GATE_PD1`~`GATE_PD6` | MOS Gate | 10k → GND | 0.25mm，**上电不误开的关键** |
| `FLY1`~`FLY6` | 1N4007 阴极→泵 +、阳极→泵 − | 就近并在泵端子旁 | 0.8mm |
| `3V3` | ESP32 3V3 | 继电器 DC+ / COM（或 P-MOS S） | ≥0.5mm + 470µF |
| `VCC_S` | 继电器 NO（或 P-MOS D） | 6 个探头端子 VCC | ≥0.5mm |
| `AOUT1`~`AOUT6` | 探头端子 AOUT | ESP32 ADC 脚 | 0.25mm，**包地、远离泵线** |
| `AOUT_PD1`~`AOUT_PD6` | AOUT | 100k → GND | 0.25mm，必须有 |
| `SENSOR_PWR_CTRL` | ESP32 D27 | 继电器 IN（或 P-MOS G） | 0.3mm |
| `GND` | 全板 | — | 底层铺铜，多打地过孔 |

## 五、布局分区

```
┌──────────────────────────── 板框 100 × 75mm ────────────────────────────┐
│ 天线净空区（禁铺铜/禁元件，模块伸出板边）                                │
│  ┌──────────────┐        3V3 / GND / 5V_P 三条汇流排横贯                │
│  │  ESP32 插座  │   ┌──────────────────────────┐   ┌─────────────────┐  │
│  │  2×15 排母   │   │  Q1~Q6 + 100Ω/10k/1N4007 │   │ JP1~JP6 泵端子  │  │
│  │  （左侧）    │   │  低边驱动区（中部）        │   │ J0 5V 输入      │  │
│  └──────────────┘   └──────────────────────────┘   │ （右侧功率区）   │  │
│  ┌──────────────────────────────────────────────┐  └─────────────────┘  │
│  │ JS1~JS6 探头端子 · 100k 下拉 · K1/Q7 供电开关 │                       │
│  │ （下方信号区，远离右侧 5V 粗铜皮）             │                       │
│  └──────────────────────────────────────────────┘                       │
└─────────────────────────────────────────────────────────────────────────┘
```

**强弱电分区是硬要求**：右侧 5V 粗铜皮和泵回路，与下方 AOUT 信号线**不要平行长距离走线**，中间用地平面隔开。泵启停的电流突变会耦合进 ADC，表现为「一浇水其他路读数乱跳」。

## 六、两个版本，固件改动不同

| | V1 保守版（建议先做） | V2 全贴片版 |
|---|---|---|
| 探头供电 | 板上留 6P 端子，外接现有 JQC-3FF 继电器模块 | P-MOS 高边开关焊在板上 |
| 电路 | 端子：`DC+ / DC− / IN / COM / NO`（+ 3V3） | 3V3→P-MOS S，D→VCC_S，G→D27 + 10k 上拉到 3V3 |
| 固件 | **一个字都不用改**，不用重烧 | `config.h` 里 `SENSOR_PWR_ACTIVE_LOW` 由 `0` 改成 `1`，重编译烧录一次 |
| 优点 | 复用现有元件、零风险、已实测通 | 无继电器浪涌、无触点氧化、板子更小巧无声 |
| 缺点 | 板上多一块外接模块、有吸合声 | 要改一行固件并重烧 |

V2 的 10k 上拉很关键：复位期间 GPIO27 高阻，上拉把 P-MOS 栅极拉到 3V3（Vgs≈0）保持关断，探头不会意外上电。这和现有的 `config.h` 方案 B 描述一致。

**`PUMP_ACTIVE_LOW = 0` 两版都保持不变** —— 低边 N-MOS 高电平导通，板上和现在飞线完全一致。

## 七、下单前检查清单

1. **量排针中心距**（25.4 还是 22.86mm），核对排母封装
2. **天线净空区**确认无铜、无元件、无丝印覆盖，模块天线端伸出板边
3. DRC 通过；`5V_P` 与 `GND` 间距 ≥0.5mm，泵回路铜皮够宽
4. 所有电解电容、1N4007、MOS 的 **G/D/S 极性丝印**核对一遍
5. 底层 GND 铺铜，功率区多打地过孔；AOUT 线两侧包地
6. 每个网络在 `pcb/netlist.csv` 里都能对上，**尤其是 6 个 10k 栅极下拉和 6 个 100k AOUT 下拉**（最容易漏）
7. 导出 Gerber 后用 Gerber 查看器看一遍板框、孔径、阻焊开窗

## 八、板子回来怎么验

1. **空板**：万用表量 5V ↔ GND 不短路，所有 GND 全通
2. **只焊最小系统**：电源部分 + 两个排母 + 去耦，插 ESP32，USB 供电看能否启动、WiFi 能否连上
3. **焊 1 路**：Q1 / 100Ω / 10k / 1N4007 / 100k + JP1 + JS1，接 CH1 探头，验 `raw≈2600~2900 / flt=0`
4. **点浇水**：量 TP_GATE1 变 3.3V、泵转 15 秒；不接泵也能先量电压
5. **再焊其余 5 路**，每焊一路读一次 `/api/state`；逐路点浇水看其他路读数不跳
6. 最后补 470µF 电解（若第 2 步没装），确认继电器/P-MOS 吸合瞬间不复位

## 九、和第十节的关系

第十节是**不用打板也能落地**的手工版（万能板 + 端子台），本节是同一套网络的 PCB 版。两者引脚定义、元件取值、固件完全相同，可以先按第十节用万能板验证 1~3 路，确认方案没问题再下单打板 —— 板子一旦投出去，改一根线就要等一周。

## 十一、另一块板：远端无源分线板

> 用户已决定**不做主控载板**（`我只需要一套`），本文件前十节保留作资料。下面这块是**完全不同、更小更简单**的板：装在花盆区中心的分线盒位置，替代端子 + 汇流排 + 盒内跳线。**最终形态是「进线 RJ45 水晶头 + 出线 6 个 3P 直插座」，整盒零接线、探头直插**。业务背景见 `docs/WIRING.md` **5.7 / 5.8 / 5.9** 与第十四节。

### 和主控载板的区别

| 对比 | 前十节主控载板 | 本板 |
|---|---|---|
| 位置 | 主控箱，ESP32 DevKit 插在板上 | 花盆区分线盒 |
| 元件 | MOS ×6、续流二极管、LDO、电解、2×15 排母 | **无有源元件**，只有连接器（RJ45 + 6×3P 座）+ 可选 0805 / 0603 焊位 |
| 电流 | 泵 5V / 数 A，需 2oz 铜与 AWG18 | VCC_S 仅 30~120mA / 3.3V，**1oz 足够** |
| 难点 | 天线净空、排母中心距、电源分区 | 只有线序丝印与 AOUT 走线间距 |
| 层数 / 尺寸 | 2 层 100×75mm | **2 层 70×50mm**（出线改 3P 直插座并排 6 个时建议 80×50mm） |
| 网表 | `docs/pcb/netlist.csv`（66 条） | 本节 20 条 |

### 规格与布局

2 层 FR-4 / 1.6mm / 1oz / 绿油白字 / 有铅喷锡 / **70×50mm**（出线改 6 个 3P 直插座并排时建议 **80×50mm**），都落在 10×10cm 免费打样条件内（第十节）；4 个 M3 安装孔 + 铜柱垫高 5mm。

```
左侧 1× RJ45 8P8C 母座（或 KF301-8P 二选一焊位）──→ 中部 VCC_S / GND 各一条 2mm 铜皮汇流 ──→ 右侧 6× 3P 出线位
   丝印印 T568B pin 号 + 线色    6 条 AOUT 短直走线（间距 ≥2W）     3P 直插座 或 KF301-3P 二选一焊位
                                                                  印 CH1~CH6 / VCC / GND / AOUT / 缺口方向
```

`VCC_S` 铺铜**不要覆盖 AOUT 走线下方**（分布电容耦合）；每路留 `100kΩ` 0805 与 `100nF` 0603 焊位：

- **端子版**：默认 NC 不装 —— 按 WIRING 5.6，电阻并在探头插头根部；只有选「盒内侧」备选方案才在板上贴，且此时探头端不再并。
- **3P 直插版**：**推荐把 6 只 100kΩ 0805 直接贴到板上**，探头端彻底干净、插头才插得进（理由见下一节）；此时探头端 / 插头上都不要再并，否则同路两只并联成 50k、干湿点标定值要重做。

`100nF` 仅 10~30m 时装。

### 进线改 RJ45 水晶头（推荐版）

**能加，而且比 `KF301-8P` 更合适。** 网线单芯 24AWG ≈ 0.2mm²，`KF301` / `TB-1508` 这类螺钉端子压不紧，虚接几个月后读数就飘（WIRING 5.2）；水晶头压接是网线的标准工艺，8 根芯一次压完、接触电阻小、不会松，还顺带省掉盒端 8P 端子和一盒 `E0508` 管形端子。

**买哪种座（这里最容易买错）**

| | 搜词 / 特征 |
|---|---|
| **要买** | `8P8C RJ45 母座 直插 180度 无灯 无变压器` / `网线插座 PCB 立式 8P8C`；普通 8 个触点直通、可过直流，最好选镀金触点 |
| **绝对别买** | `HR911105A`、`带网络变压器`、`带 LED 指示灯`、`以太网网口模块`、`RJ45 网络滤波器` —— 这类是给以太网 PHY 用的，内部串了 1:1 隔离变压器和中心抽头，**直流完全隔断**，3.3V 探头供电和 0~3V 的 AOUT 一路都过不去，板子直接不通 |
| 不用买 | `RJ45 母对母直通头 / 网络对接头`（转接件，不是 PCB 焊接座） |

RJ45 座占位约 16×21mm，比 `KF301-8P`（8×5.08 ≈ 41mm 长）**还短**，70×50mm 完全够，不必改板框；开口朝板边、弹片朝盒内侧，插拔方向留出 ≥20mm 空间。**建议把 RJ45 座与 `KF301-8P` 画成同一组 8 个网络的二选一并联焊位**，5 片板回来想用哪种焊哪种（只焊一个、只插一个），几 mm 的 stub 对 ADC 无影响。

**T568B 引脚映射（关键：RJ45 pin 号 ≠ 原端子编号）**

水晶头两端**都按 T568B 压，直通线，不要做交叉线**。弹片朝下、金属触点朝自己，从左到右 pin1~8：

| RJ45 pin | T568B 线色 | 本板网络 | 主控端 | 原 `KF301-8P` 位号 |
|---|---|---|---|---|
| 1 | 橙白 | `AOUT1` | `VP / GPIO36` | `JIN.1` |
| 2 | 橙 | `AOUT2` | `VN / GPIO39` | `JIN.2` |
| 3 | 绿白 | `AOUT3` | `D34` | `JIN.3` |
| 4 | **蓝** | `AOUT6` | `D33` | `JIN.6` |
| 5 | **蓝白** | `AOUT5` | `D32` | `JIN.5` |
| 6 | **绿** | `AOUT4` | `D35` | `JIN.4` |
| 7 | 棕白 | `VCC_S` | 继电器 `NO` | `JIN.7` |
| 8 | 棕 | `GND` | ESP32 `GND` | `JIN.8` |

> **最要命的一个坑**：第十四节原来那张色序表是给 `KF301-8P` 自编的位号（4=绿 / 5=蓝白 / 6=蓝），而 **T568B 的 pin4/5/6 是 蓝 / 蓝白 / 绿，正好反着**。换 RJ45 时**不能把 `JIN.4/5/6` 直接当成 `RJ.4/5/6`**，否则 CH4/CH5/CH6 三路全错位，现象是「三路读数一模一样或全 `flt=1`」。上面的表按**线色**对应，颜色不变、业务通道不变，只是 pin 号重排。
>
> **第二个坑**：RJ45 母座在 PCB 上的焊盘编号**不一定等于水晶头触点编号**（带定位脚、带弹片、不同厂家会反序）。画板前先插一根按 T568B 压好的短网线，用万用表通断档**逐脚实测触点 ↔ 焊盘**，以实测结果定网表，别照抄任何型号图纸。

**主控端怎么收口**：主控箱那头要散到 ESP32 的 8 个针脚，最省事是买一块成品 `RJ45 母座转 8P 螺丝端子板` / `网线转接板 RJ45 to terminal`（约 ¥3~8），8 个端子位印 1~8，按 T568B 色表把橙白→`VP`、橙→`VN`…棕白→继电器 `NO`、棕→`GND` 接上；网线细芯进螺钉端子仍要套 `E0508` 管形端子或对折双股。也可拿 5 片板中的一片只焊 `RJ45 + 8P 端子` 当主控端转接板。

**这几条不能破**

1. **这个口只过探头供电和 6 路高阻 AOUT**：`VCC_S` 最大约 120mA / 3.3V，6 只探头 20mA 一只，RJ45 触点余量很大。**泵 5V / 数 A 绝不能走 RJ45**，电源和两块 YYNMOS-4 全部留在主控箱。
2. **RJ45 不防水**：照样按 WIRING 5.1 装倒扣盒、插口朝下、孔在底面；插好后接头外套一段带胶热缩管或自粘胶带缠住（别把热缩管烘到塑料座变形），潮湿处选镀金触点。户外段用**室外型 PE 护套超五类**（抗 UV），室内线露天一两年外皮就粉化。
3. **距离上限不变**：改成水晶头只是接头形式变了，线径和 4 对双绞没变，仍按 ≤10m 默认；10~30m 照 WIRING 第十四节第 7 步换两根屏蔽网线并装板上 `100nF`，>30m 搬主控。RJ45 化**不会**把 10m 变成 100m。
4. 屏蔽网线（STP）+ 金属壳座时，**屏蔽层只在主控端接 ESP32 GND**，分线盒端剪断包绝缘；两头都接成地环路反而更吵。UTP 非屏蔽最省事。
5. 水晶头插拔寿命有限，装好后别反复拔；要改线在主控端端子板上改。

**成本变化**：RJ45 座 ¥0.5~2、水晶头 ¥0.1~0.3/个（一包 20 个 ¥2~5）、最便宜压线钳 ¥15~25（可借，或直接买成品网线剪一头只压另一端）、主控端转接板 ¥3~8；同时省掉盒端 8P 端子和管形端子。**有免费券打板的总额基本不变（仍约 ¥10~15）**，白拿一个更可靠的接头。

**第一批只有 CH1 也能先压**：干线两端照样 8 芯全压满，主控端只接 橙白 / 棕白 / 棕 3 根，其余 5 根贴好标签留空；板上只装 CH1 的 3P 端子，CH2~CH6 空着显示 `flt=1` 属正常。后面扩路直接把剩下的芯接上，不用重压线。

### 出线改 3P 直插座：探头免接线直插

**对，打板的最终形态就该是这样** —— 板上 6 个 3P 座 + 进线 1 个 RJ45 座，整个分线盒里 **0 根跳线、0 根短线、0 个螺丝孔**，探头线插上就完事，连"压 18 根三芯线"都省了。这是 70×50mm 无源板最干净的用法。

**但先确认插头方向别买反**：手上 HW-390 是**板上一个 PH2.0-3P 白色座 + 一根转接线**，转接线末端是**三个独立的 2.54mm 杜邦母头**（WIRING 第十二节「端子形状不匹配」已记）。母头要插的是**公针**，所以板上焊的严格说是 **3P 公座 / 直排针**；口语说的「3P 母座」如果指"座子"没问题，如果真买成 **3P 母座（孔）就会母对母插不上**。

| 探头线末端实物 | 板上该焊 | 搜词 | 防呆 |
|---|---|---|---|
| 三个散的 2.54 杜邦母头（**当前这套**） | `3×1 2.54 直排针` 或 `XH2.54-3P 直针座` | `XH2.54-3P 直针座 带扣` / `3P 2.54 直排针` | 散杜邦头**没有防呆** |
| 一体 PH2.0 白色 3P 公插头 | `PH2.0-3P 直针座` | `PH2.0-3P 直针座 卧贴/立贴` | 带凸台，最好 |

> **下单前拿卡尺量一下**：插头相邻两针中心距 **2.0mm → PH2.0**，**2.54mm → 杜邦 / XH2.54**，买错完全插不进。XH2.54 与杜邦胶壳的卡扣**互不通用**，要买就买配套的座 + 胶壳；想彻底防呆，把三个散杜邦母头压进一只 `3P 2.54 杜邦母胶壳`（¥0.1），板上焊带扣的 3P 直针座，插反插不进去。

**三个直插特有的坑**

1. **线长最要命**。原设计「分线盒放 6 只探头几何中心、每根 ≤2m 短线」的前提是能自己剪线；探头自带转接线通常只有 **20~30cm**，直插就等于要求 6 只探头都挤在板子 30cm 内。两条出路：把花盆往板子边靠；或买 **3P 2.54 公对母延长线 1~2m**（成品 ¥1~2/根，6 根 ¥6~12，仍是直插、不用压线），PH2.0 版本同理买 `PH2.0-3P 延长线`。**别为了直插把板子挪离几何中心去迁就一根短线**，那样 6 根模拟线又变长了。
2. **100kΩ 别再并在插头上**。5.6 默认的「探头插头根部并电阻 + 双壁含胶热缩管」会让插头鼓包，插不进 3P 座、相邻座还会打架。直插版改走 5.6 的**盒内侧备选**：把 6 只 `100k 0805` 贴到板上现成的 NC 焊位（等价于电阻固定在远端的座位上），或焊到探头 PCB 的 `AOUT/GND` 焊盘（5.6 做法 B）。**两处只选一处**。代价按 5.6「一个诚实的例外」：拔掉探头后主控侧 AOUT 悬空，但 `36/39/34/35` 无内部上拉、实测 `raw=0/65/60 < ADC_OPEN_RAW(400)`，仍稳定判 `FLT_OPEN`，不会误开泵。
3. **插反代价很大**。3P 座必须 6 个方向完全一致，座旁丝印印 `CH1…CH6` + `VCC / GND / AOUT` + **缺口方向三角标记**；插反把 3.3V 顶到 AOUT 会读成满湿度、可能乱开泵。散杜邦头没有防呆，第一次插之前用万用表按座上丝印逐根对一遍。

**布局与机械**

- `XH2.54-3P` 带扣座宽约 9~10mm，6 个并排按 ≥11mm 中心距要 66mm，加板边和 M3 孔 **70mm 宽很紧 → 建议板框放宽到 80×50mm**（仍在免费打样内）；`PH2.0-3P` 窄约 6.5mm，70mm 够。也可排成 **2 排各 3 个**保持 70×50mm。
- 座子选**直针（垂直板面插）**还是**卧式（贴板边水平插）**取决于盒子：板平放、座朝上最好插但最容易积水；建议板**竖装或斜装**、插口朝侧面或略朝下，与 5.1 的"孔朝下 + 倒扣盒"一致。
- 探头线被拉扯时力**直接传到 PCB 焊盘**，比螺丝端子脆弱得多：板边每个座旁留一个 **Ø3 扎带孔 / 线卡位**，插好后用扎带把探头线束固定在板上，或点一点热熔胶在胶壳上（别糊住触点、别用酸性硅胶）。座子选带扣款，别用裸排针长期露天。

**防水**：PH2.0 / 杜邦 / XH 座都**不防水**，而且不能像螺丝端子那样整束灌胶。按 WIRING 5.1 装倒扣盒、插口朝下、板面刷一层三防漆（**避开座内触点与插合面**）；插头外套一小段带胶热缩管只能护线、护不了插合面，真正管用的还是"换位置不淋雨"。凝露会让 `VCC_S` 与相邻 AOUT 漏电，盒内放干燥剂。

**成本**：省掉 `KF301-3P`×6（约 ¥6）、18 根三芯短线、压线工时与管形端子；改买 6 个 3P 座（¥1~3）+ 6 根延长线（按需 ¥6~12）+ 板上 6 只 100k 0805（几分钱）。**有免费券打板总额仍约 ¥10~20**，换来的是"整盒零接线"。

**验收**：断电通断档量 `RJ45 pin7` ↔ 6 个座的 `1(VCC)` 全通、`pin8` ↔ 6 个座的 `2(GND)` 全通、各座 `1/2/3` 两两不短、任意两路 `3(AOUT)` 不导通；板上贴了 100k 的话，每路 `3 ↔ 2` 应量到约 100kΩ。再只插 CH1 一只探头，上电应 `flt=0 / raw 1000~3000`、其余 5 路 `flt=1`；若 CH1 `raw` 顶满或 `flt=1`，**立刻断电查插头有没有插反**。

### 回板验证

1. 空板目检：铜皮无桥连、6 条 AOUT 之间无短路、丝印的 **T568B pin 号 + 线色** 与第十四节第 3 步线序表逐项对照。
2. 万用表通断档：`pin7 / JIN.7`（棕白）↔ `J1…J6.1` 全通；`pin8 / JIN.8`（棕）↔ `J1…J6.2` 全通；**任意两路 AOUT 之间不导通**；AOUT ↔ VCC_S 不导通。
   - **RJ45 版必做**：插一根两端按 T568B 压好的短网线，从另一端水晶头触点逐脚量到 6 个 3P 端子 —— `pin1→J1.3`、`pin2→J2.3`、`pin3→J3.3`、`pin6(绿)→J4.3`、`pin5(蓝白)→J5.3`、`pin4(蓝)→J6.3`。这一步同时验了「母座焊盘编号是否等于触点编号」，是防 CH4/5/6 错位的唯一保险。
3. 通电前按上面「出线改 3P 直插座」的验收段量一遍：`pin7` ↔ 6 个座 `1(VCC)` 全通、`pin8` ↔ `2(GND)` 全通、各座 `1/2/3` 两两不短、任意两路 `3(AOUT)` 不导通；板上贴了 100k 时每路 `3 ↔ 2` ≈ 100kΩ。
4. 焊上座 / 端子后逐路按 `docs/WIRING.md` 第十四节第 6 步验收（CH1 `flt=0` / raw 1000~3000，其余 `flt=1`）；直插版若 CH1 `raw` 顶满或 `flt=1`，**先断电查插头有没有插反**，再查线序。
5. 板子不防水：仍按 WIRING 5.1 装倒扣盒 / 孔朝下，或刷三防漆（**避开座内触点与插合面**，也别刷到端子接触面）。

**固件全程不用改、不用重烧**：这块板只做无源转接，`CHANNEL_COUNT = 6`、六路 ADC 引脚、采样时序、故障判定都是现成的。
