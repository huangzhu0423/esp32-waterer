# 打一块载板：把 60 根线变成一束排线 + 若干端子

## 零、结论与边界

**可以打，推荐打。** 第十节的「分配板」本质就是一块手工版本的 PCB，把 3 条汇流排、6 路 MOS、24 个阻容、全部端子固化到板上，飞线只剩探头线和泵线。

三条边界必须先划清楚，否则打回来的板装不上或不能用：

| 不进 PCB | 原因 | 正确做法 |
|---|---|---|
| ESP32 芯片 / WiFi 射频 | 射频布局、天线净空、阻抗不是 DIY 能一次做对的 | 用 **2×15 排母**把现成的 DevKit 模块插上去，坏了也能换 |
| 6 个水泵本体 | 大电流、要防水、要能单路更换 | 板上只留 **2P 可插拔螺丝端子** |
| 6 个探头本体 | 线要拉到花盆，长度不定 | 板上只留 **3P 可插拔端子** |

> **最容易被忽略的坑**：ESP32 DevKit 是板载 PCB 天线。载板在天线投影区域**绝不能铺铜、不能放元件、不能走线**，最好让模块天线那一端**伸出板边 5mm 以上**。不做净空，WiFi 会明显变差甚至连不上路由器，而远程页全靠 WiFi。

**排针中心距要实测**：30 针 DevKit 常见两排中心距 **25.4mm**，但也有 **22.86mm** 的窄版。下单前用游标卡尺量手上这块，再定两个排母的间距；排母用 2.54mm 间距、2×15。

## 一、板子规格

| 项目 | 取值 |
|---|---|
| 层数 | **2 层**（6 路低速直流，没必要 4 层） |
| 板材 / 板厚 | FR-4 / **1.6mm** |
| 铜厚 | 1oz 够用，**2oz 更稳**（泵 1.5A 峰值压降更小，加价不多） |
| 建议尺寸 | 约 **100 × 75mm**，压在 10×10cm 内打样最便宜 |
| 最小线宽 / 线距 | 0.25mm / 0.25mm（常规 6/6mil 工艺） |
| 过孔 | 0.6mm 孔 / 0.3mm 钻，盖油 |
| 表面处理 | 无铅喷锡或沉金；绿油白字 |
| 安装孔 | 4 × M3（孔径 3.2mm），四角各留 5mm 禁布区 |
| 打样 | 2 层 10×10cm 内通常是几十元 / 5 片、2~4 天出货，**以官网实时报价为准** |

## 二、板上集成什么

| 区域 | 内容 |
|---|---|
| ESP32 插座区 | 2×15 排母 ×2（或一条 2×15 双排座）、3V3 去耦、天线净空区 |
| 汇流排 | 3V3（VCC_S）、GND 地平面、5V_P 粗铜皮，横贯板中部 |
| 低边驱动区 | 6 × N-MOS + 每路 100Ω / 10k / 1N4007 / 100nF |
| 探头信号区 | 每路 100k 下拉，可选 1k + 100nF 的 RC 滤波 |
| 探头供电 | V1 留 6P 端子外接继电器模块；V2 焊 P-MOS 高边（见第六节） |
| 端子区 | 5V 输入 2P、泵 6×2P、探头 6×3P，全部可插拔 |
| 测试点 | 每路 Gate / AOUT 各 1 个，3V3 / 5V / GND 各 1 个 |

**丝印必须标**：`CH1`~`CH6`、每个 ESP32 引脚的丝印名（`VP/VN/D34/D35/D32/D33`、`D13/D18/D19/D23/D25/D26`、`D27`）、电解电容 `+`、1N4007 阴极方向、所有端子极性。装错一根线要拆半天，丝印是最便宜的保险。

## 三、网络表

完整逐行版见 [`pcb/netlist.csv`](pcb/netlist.csv)，画原理图时按它逐个核对，避免漏网。主干网络：

| 网络 | 从 | 到 | 线宽 / 做法 |
|---|---|---|---|
| `5V_P` | 5V 输入 + | 6 个泵端子 1 脚 | **≥2mm 铜皮或铺铜区**，1.5A 峰值 |
| `PGND` | 5V 输入 − | 6 个 MOS Source | 底层**整片地平面** |
| `PUMP1_N`~`PUMP6_N` | 泵端子 2 脚 | 对应 MOS Drain | ≥1.0mm，每路 0.8A |
| `GATE1`~`GATE6` | ESP32 泵脚 | 串 100Ω → MOS Gate | 0.3mm |
| `GATE_PD1`~`GATE_PD6` | MOS Gate | 10k → GND | 0.25mm，**上电不误开的关键** |
| `FLY1`~`FLY6` | 1N4007 阴极→泵 +、阳极→泵 − | 就近并在泵端子旁 | 0.8mm |
| `3V3` | ESP32 3V3 | 继电器 DC+ / COM（或 P-MOS S） | ≥0.5mm + 470µF |
| `VCC_S` | 继电器 NO（或 P-MOS D） | 6 个探头端子 VCC | ≥0.5mm |
| `AOUT1`~`AOUT6` | 探头端子 AOUT | ESP32 ADC 脚 | 0.25mm，**包地、远离泵线** |
| `AOUT_PD1`~`AOUT_PD6` | AOUT | 100k → GND | 0.25mm，必须有 |
| `SENSOR_PWR_CTRL` | ESP32 D27 | 继电器 IN（或 P-MOS G） | 0.3mm |
| `GND` | 全板 | — | 底层铺铜，多打地过孔 |

> **MOS 选型别踩坑**：必须是**逻辑电平 N-MOS**，3.3V 栅极能完全导通。AO3400（SOT-23，约 5A）、IRLZ44N（TO-220）都行；**IRF520 不行**，它要 5V 以上才饱和，3.3V 驱动会半导通发热。

## 五、布局分区

```
┌──────────────────────────── 板框 100 × 75mm ────────────────────────────┐
│ 天线净空区（禁铺铜/禁元件，模块伸出板边）                                │
│  ┌──────────────┐        3V3 / GND / 5V_P 三条汇流排横贯                │
│  │  ESP32 插座  │   ┌──────────────────────────┐   ┌─────────────────┐  │
│  │  2×15 排母   │   │  Q1~Q6 + 100Ω/10k/1N4007 │   │ JP1~JP6 泵端子  │  │
│  │  （左侧）    │   │  低边驱动区（中部）        │   │ J0 5V 输入      │  │
│  └──────────────┘   └──────────────────────────┘   │ （右侧功率区）   │  │
│  ┌──────────────────────────────────────────────┐  └─────────────────┘  │
│  │ JS1~JS6 探头端子 · 100k 下拉 · K1/Q7 供电开关 │                       │
│  │ （下方信号区，远离右侧 5V 粗铜皮）             │                       │
│  └──────────────────────────────────────────────┘                       │
└─────────────────────────────────────────────────────────────────────────┘
```

**强弱电分区是硬要求**：右侧 5V 粗铜皮和泵回路，与下方 AOUT 信号线**不要平行长距离走线**，中间用地平面隔开。泵启停的电流突变会耦合进 ADC，表现为「一浇水其他路读数乱跳」。

## 六、两个版本，固件改动不同

| | V1 保守版（建议先做） | V2 全贴片版 |
|---|---|---|
| 探头供电 | 板上留 6P 端子，外接现有 JQC-3FF 继电器模块 | P-MOS 高边开关焊在板上 |
| 电路 | 端子：`DC+ / DC− / IN / COM / NO`（+ 3V3） | 3V3→P-MOS S，D→VCC_S，G→D27 + 10k 上拉到 3V3 |
| 固件 | **一个字都不用改**，不用重烧 | `config.h` 里 `SENSOR_PWR_ACTIVE_LOW` 由 `0` 改成 `1`，重编译烧录一次 |
| 优点 | 复用现有元件、零风险、已实测通 | 无继电器浪涌、无触点氧化、板子更小巧无声 |
| 缺点 | 板上多一块外接模块、有吸合声 | 要改一行固件并重烧 |

V2 的 10k 上拉很关键：复位期间 GPIO27 高阻，上拉把 P-MOS 栅极拉到 3V3（Vgs≈0）保持关断，探头不会意外上电。这和现有的 `config.h` 方案 B 描述一致。

**`PUMP_ACTIVE_LOW = 0` 两版都保持不变** —— 低边 N-MOS 高电平导通，板上和现在飞线完全一致。

## 七、下单前检查清单

1. **量排针中心距**（25.4 还是 22.86mm），核对排母封装
2. **天线净空区**确认无铜、无元件、无丝印覆盖，模块天线端伸出板边
3. DRC 通过；`5V_P` 与 `GND` 间距 ≥0.5mm，泵回路铜皮够宽
4. 所有电解电容、1N4007、MOS 的 **G/D/S 极性丝印**核对一遍
5. 底层 GND 铺铜，功率区多打地过孔；AOUT 线两侧包地
6. 每个网络在 `pcb/netlist.csv` 里都能对上，**尤其是 6 个 10k 栅极下拉和 6 个 100k AOUT 下拉**（最容易漏）
7. 导出 Gerber 后用 Gerber 查看器看一遍板框、孔径、阻焊开窗

## 八、板子回来怎么验

1. **空板**：万用表量 5V ↔ GND 不短路，所有 GND 全通
2. **只焊最小系统**：电源部分 + 两个排母 + 去耦，插 ESP32，USB 供电看能否启动、WiFi 能否连上
3. **焊 1 路**：Q1 / 100Ω / 10k / 1N4007 / 100k + JP1 + JS1，接 CH1 探头，验 `raw≈2600~2900 / flt=0`
4. **点浇水**：量 TP_GATE1 变 3.3V、泵转 15 秒；不接泵也能先量电压
5. **再焊其余 5 路**，每焊一路读一次 `/api/state`；逐路点浇水看其他路读数不跳
6. 最后补 470µF 电解（若第 2 步没装），确认继电器/P-MOS 吸合瞬间不复位

## 九、和第十节的关系

第十节是**不用打板也能落地**的手工版（万能板 + 端子台），本节是同一套网络的 PCB 版。两者引脚定义、元件取值、固件完全相同，可以先按第十节用万能板验证 1~3 路，确认方案没问题再下单打板 —— 板子一旦投出去，改一根线就要等一周。
